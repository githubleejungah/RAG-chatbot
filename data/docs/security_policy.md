# 구름노트 보안 정책 (실습용 가상 제품)

모든 메모는 전송 중에 TLS로, 서버에 저장될 때 AES-256으로 암호화됩니다. 직원은 사용자가 고객 지원을 위해 동의한 경우에만 메모를 열람할 수 있습니다.

비밀번호는 12자 이상이어야 하며, 영문과 숫자를 모두 포함해야 합니다. 2단계 인증은 인증 앱과 문자 메시지 방식을 지원하고, 설정의 보안 화면에서 켤 수 있습니다.

로그인에 5회 연속 실패하면 계정이 15분 동안 잠깁니다. 새로운 기기에서 로그인하면 가입한 이메일로 알림이 발송됩니다.

자동 로그아웃 시간은 기본 14일이며, 설정의 보안 화면에서 1일에서 30일 사이로 바꿀 수 있습니다.

계정 도용이 의심되면 즉시 비밀번호를 바꾸고 모든 기기에서 로그아웃한 뒤 고객센터로 신고하세요.
