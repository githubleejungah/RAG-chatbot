# 구름노트 사용법 (실습용 가상 제품)

새 메모를 만들려면 화면 왼쪽 아래의 더하기 버튼을 누르거나 Ctrl+N을 누르세요. 메모는 입력하는 동안 자동으로 저장됩니다. 인터넷이 끊겨도 기기에 저장되고, 다시 연결되면 자동으로 동기화됩니다.

메모는 폴더와 태그로 정리할 수 있습니다. 태그는 본문에 샵 기호와 단어를 함께 입력하면 만들어집니다. 메모 하나에 태그를 20개까지 붙일 수 있습니다.

메모를 내보내려면 메모 메뉴에서 내보내기를 선택하세요. PDF와 마크다운 형식을 지원합니다. 폴더 전체를 내보내면 ZIP 파일로 묶어 저장합니다.

삭제한 메모는 휴지통으로 이동해 30일 동안 보관되고, 그 뒤에 자동으로 지워집니다. 휴지통에서 복원을 누르면 원래 폴더로 돌아갑니다.

메모를 다른 사람과 공유하려면 공유 버튼을 눌러 링크를 만드세요. 공유 링크의 기본 권한은 읽기 전용이며, 편집 권한은 프로 요금제에서만 줄 수 있습니다.
